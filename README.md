\# GitSummarizer



GitSummarizer is an AI-powered application that helps users understand GitHub repositories by generating project overviews, feature summaries, prerequisites, and commit digests.



\## Technology Stack



\- Frontend: React, Vite, Tailwind CSS

\- Backend: FastAPI

\- Database: SQLite initially

\- External services: GitHub REST API and an LLM provider



\## Project Structure



\- `frontend/` — Frontend application

\- `backend/` — FastAPI application

\- `docs/` — Architecture and integration agreements

\- `tests/` — Automated tests



\## Development Status



Initial project structure and backend health-check scaffold.



\## Getting Started



See the backend requirements and the integration contract in `docs/integration-contract.md`. Setup instructions will be expanded as the application develops.
